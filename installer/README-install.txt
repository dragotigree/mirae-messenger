미래병원 메신저 — 설치 안내
================================

■ 다른 PC에 설치하는 방법
1. 이 ZIP 파일 전체를 USB/공유폴더로 복사합니다.
2. 압축을 풉니다.
3. 「MiraeMessenger-Setup.cmd」 를 더블클릭합니다.
4. 안내에 따라 설치합니다. (관리자 권한 불필요)

■ 설치 위치 (기본)
  %LOCALAPPDATA%\MiraeMessenger

■ 제거
  설치 폴더의 「제거.bat」 또는 제거 스크립트(uninstall.ps1)

■ 주의
  - exe 파일만 복사하면 실행되지 않습니다. 반드시 설치 프로그램을 사용하거나
    MiraeMessenger-win32-x64 폴더 전체를 같은 구조로 복사해야 합니다.
  - Windows Defender 등에서 차단되면 「추가 정보 → 실행」을 선택하세요.
    (사내에서 만든 프로그램이라 코드 서명이 없을 수 있습니다.)

■ 업데이트
  프로그램 환경설정의 「프로그램 업데이트」 또는
  공유폴더(Z:\...\messenger)의 최신 버전으로 재설치하세요.
