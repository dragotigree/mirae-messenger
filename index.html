🔔 메시지 알림
알림 방식
토스트와 데스크탑 중 하나만 사용합니다. 기본값은 토스트입니다.

토스트의 열기는 해당 대화로 이동하고, 닫기는 바로 숨깁니다. 이미 그 대화를 보고 있을 때는 새 메시지 알림을 띄우지 않습니다. 같은 상대가 연속으로 보내도 알림은 1개만 표시됩니다.

앱을 켤 때와 설정 저장 시 선택한 화면으로 전환됩니다. 사이드바 하단 좁은 창 아이콘으로도 바꿀 수 있습니다.
메뉴·사이드바·설정·일정판·버튼 등 UI 전체에 적용됩니다.
1:1·그룹·방송·부서·층 채팅 말풍선 글씨에만 적용됩니다.
💾 대화 내용 백업

프로그램 연결 초기화 실패

보안 연결(preload) 스크립트를 읽지 못했습니다. OneDrive·공유폴더 동기화 중이거나, 업데이트 파일이 사용 중일 때 발생할 수 있습니다.

  • 트레이에서 메신저를 완전히 종료한 뒤 다시 실행해 주세요.
  • 작업 관리자에서 MiraeMessenger 프로세스가 남아 있지 않은지 확인해 주세요.
  • 설치 경로가 OneDrive 안이면 로컬 폴더(C:\ 등)로 옮기는 것을 권장합니다.
  • 1.0.142 이상이면 preload가 자동으로 로컬 캐시(%AppData%)에 복사되어 재발이 줄어듭니다.
