01

이 프로그램은 무엇인가요?

미래병원 사내 메신저는 병원 안 컴퓨터끼리 글·사진·파일을 주고받는 프로그램입니다.

🏥
병원 안에서만

같은 병원망(내부망)에서 동작합니다. 일반 카카오톡이 아닙니다.

💻
PC에 기록이 남음

대화는 내 컴퓨터에 저장됩니다. 두세 달 전 글도 찾아볼 수 있습니다.

🔔
알림으로 알려 줌

새 메시지가 오면 화면에 알림이 뜹니다. (설정에서 끌 수 있음)

⬇️
창을 닫아도 켜져 있음

창을 닫으면 오른쪽 아래 아이콘에 남습니다. 완전히 끄려면 「종료」를 누릅니다.

화면 구성 (기본 화면)

왼쪽직원 목록 · 부서/층 · 그룹 · 공지
가운데대화 내용 · 글 쓰는 칸 · 전송 버튼
오른쪽상대 정보 · 달력 · 일정
다른 층 직원과도 됩니다.
목록에 이름이 보이고 상대 컴퓨터가 켜져 있으면, 글·사진·파일을 보낼 수 있습니다.

02

메신저 창 열기

방법 A — 아이콘으로 열기 (가장 쉬움)

  1. 화면 오른쪽 아래(시계 근처)에서 메신저 아이콘을 찾습니다.
    (아이콘이 안 보이면 ▲ 또는 ^ 표시를 눌러 숨은 아이콘을 펼쳐 보세요.)
  2. 아이콘을 마우스 오른쪽 버튼으로 누릅니다.
  3. 「메시지 보내기」를 누릅니다. → 창이 열립니다.

방법 B — 키보드

Ctrl + Alt + S 를 같이 누르면 창이 열립니다.

아이콘 오른쪽 클릭 메뉴에서 자주 쓰는 것

메시지 보내기메신저 창 열기
전체 주고받은 메시지예전 대화 찾기
환경 설정내 이름·알림·업데이트
기본 / 미니 화면넓은 창 / 좁은 창
종료메신저 완전히 끄기
주의
창의 X(닫기)는 “잠시 숨기기”에 가깝습니다.
프로그램을 완전히 끄려면 아이콘 메뉴의 「종료」를 누르세요.

03

메시지 보내기

한 사람에게 보내기

  1. 왼쪽 목록에서 이름을 찾습니다.
    위쪽 검색칸에 이름·부서·층을 입력해도 됩니다.
  2. 이름을 한 번 클릭합니다.
  3. 아래 칸에 글을 씁니다.
  4. 「전송」 버튼을 누르거나, 키보드 Enter 를 누릅니다.

글 쓰는 곳 아래 버튼

📷

⏰

💬
빠른 문구자주 쓰는 말 넣기
🚨

✉️

여러 사람에게

부서 / 층그 부서·층 사람들에게
전체 공지가능한 많은 직원에게

예전 글은 전체 대화 기록 (Ctrl+Alt+E) 에서도 찾을 수 있습니다.

04

사진 · 파일 · 화면 캡처

사진 보내기

  1. 대화 상대를 먼저 고릅니다.
  2. 📎 로 사진을 고르거나,
    사진을 복사한 뒤 입력칸에서 Ctrl+V 로 붙여 넣습니다.
  3. 자동으로 크기가 줄어든 뒤 전송됩니다. (성공 시 별도 안내 없이 보내집니다)

파일 보내기

작은 파일바로 보낼 수 있습니다.
큰 파일 (최대 50MB)한 사람 또는 그룹에게만.
상대 메신저가 켜져 있어야 합니다.
더 큰 파일메신저로는 안 됩니다. 공유 폴더를 이용해 주세요.
전체 공지 · 부서 · 층 채널에는 큰 파일을 보낼 수 없습니다.
큰 파일은 1:1 또는 그룹으로 보내 주세요.

화면 캡처 (📷)

  1. 📷 버튼을 누릅니다.
  2. 「주 화면 전체」또는 「영역 캡처」를 고릅니다.
  3. 영역 캡처는 마우스로 필요한 부분만 드래그합니다.
  4. 대화에 첨부되어 전송됩니다.

받은 파일은 툴바의 폴더 아이콘으로 저장 위치를 열 수 있습니다.

05

공지 · 일정 · 이동요청

원내 공지사항

  1. 왼쪽 위 「원내 공지사항」을 누릅니다.
  2. 목록에서 글을 눌러 내용을 봅니다.

글쓰기는 권한이 있는 분만 할 수 있습니다.

오른쪽 달력 · 일정

  • 날짜를 누르면 그날 일정이 보입니다.
  • 병동 일정은 숫자 색 표시로 구분됩니다.
  • 📋 현황판을 누르면 외진·입원·퇴원 등을 한눈에 볼 수 있습니다.

일정 현황판에서 보는 것 (예)

🟠 외진외래 동행 등
🟢 입원 / 🔴 퇴원입퇴원
🟡 외출 / 🟣 외박환자 외출·외박
🩺 검사 · 🔵 전원검사·전원

이동기사 요청 🚑

  1. 이동요청 메뉴(채널)를 엽니다.
  2. 병실 · 환자명 · 치료명 · 이동 위치 · 시간을 입력합니다.
  3. 「요청 보내기」를 누릅니다.

요청이 등록되면 이동기사님 휴대폰으로 알림이 가도록 연결되어 있습니다.

설정 · 업데이트

설정 창 열기

  • 창 안 톱니바퀴(설정) 버튼
  • 또는 아이콘 오른쪽 클릭 → 환경 설정

꼭 확인해 두면 좋은 것

내 프로필이름 · 층 · 부서 · 직급 · 내선 · 사진
근무 상태온라인 / 진료·치료 중 / 자리 비움
알림새 메시지 알림 켜기·끄기, 알림 방식
글씨 크기글자가 작으면 여기서 키우기
자동 시작컴퓨터 켤 때 메신저 자동 실행
업데이트「지금 확인」으로 새 버전 받기
새 기능이 안 보여요?
설정 → 업데이트에서 「지금 확인」을 눌러 주세요.
업데이트 주소는 GitHub를 사용합니다.

목록이 비어 보일 때

  1. 상대 컴퓨터에도 메신저가 켜져 있는지 확인합니다.
  2. 툴바의 새로고침 버튼을 한 번 누릅니다.
  3. 설정 화면의 네트워크 상태(UDP / TCP)를 확인합니다.

자주 묻는 질문

Q. 창을 닫으면 메신저가 꺼지나요?
A. 아니요. 오른쪽 아래 아이콘에 남아 있습니다. 완전히 끄려면 「종료」를 누르세요.
Q. 예전 대화도 볼 수 있나요?
A. 네. 자동으로 지우지 않습니다. 대화방 검색 또는 「전체 대화 기록」을 이용하세요.
Q. 「대화창 비우기」를 하면 기록이 사라지나요?
A. 화면만 치웁니다. 컴퓨터에 저장된 기록은 남습니다.
Q. 다른 층에도 사진·파일을 보낼 수 있나요?
A. 네. 1:1(또는 그룹)이고 상대가 온라인으로 보이면 됩니다.
Q. 전송이 안 돼요.
A. 상대 메신저가 켜져 있는지, 내 목록에 이름이 있는지 확인한 뒤 새로고침을 눌러 보세요.
Q. 큰 파일을 전체 공지에 보내려고 하니 안 됩니다.
A. 맞습니다. 큰 파일은 한 사람 또는 그룹으로만 보내 주세요.
Q. 글자가 너무 작아요.
A. 환경 설정에서 글씨 크기를 키운 뒤 「설정 저장」을 누르세요.
Q. 도움이 더 필요하면?
A. 전산·메신저 담당자에게 문의하거나, 상세 문서 docs/기능-설명서.md 를 참고하세요.
