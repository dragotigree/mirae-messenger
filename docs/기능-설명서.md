# 미래병원 사내 메신저 — 기능 설명서

문서 기준 버전: **1.0.302**  
대상: 간호사·원무·치료실 등 원내 직원 및 관리자

인쇄용 쉬운 안내: `docs/메신저-사용안내-책자-A4.html` (브라우저에서 열어 A4 인쇄)

이 프로그램은 **병원 내부 PC끼리** 메시지를 주고받는 사내 메신저입니다.  
카카오톡처럼 인터넷 서버에 올리지 않고, 같은 병원망(LAN)에서 동작합니다.

---

## 1. 기본 개념

| 항목 | 설명 |
|------|------|
| 연결 방식 | PC 간 직접 통신 (UDP로 상대 찾기, TCP로 메시지·파일 전송) |
| 데이터 저장 | 각 PC의 로컬 DB에 대화·설정 저장 |
| 창을 닫으면 | 프로그램이 완전히 꺼지지 않고 **트레이(시계 옆 아이콘)** 에 남음 |
| 다른 층 | 층·부서는 목록 분류용. 1:1 대화·파일은 **상대 IP로** 전송 (다른 층이어도 가능) |

---

## 2. 프로그램 시작·화면

### 2.1 창 열기

- 화면 오른쪽 아래 **메신저 아이콘**을 더블클릭하거나, 오른쪽 클릭 → **메시지 보내기**
- 단축키: **Ctrl + Alt + S**

### 2.2 트레이 메뉴 (아이콘 오른쪽 클릭)

| 메뉴 | 기능 |
|------|------|
| 메시지 보내기 | 메신저 창 열기 |
| 전체 주고받은 메시지 열기 | 전체 대화 기록 창 (Ctrl+Alt+E) |
| 환경 설정 | 설정 창 열기 |
| 기본 / 미니 화면으로 열기 | 창 크기 모드 선택 |
| 트레이·단축키로 열 때 | 다음에 열 기본 모드(기본/미니) 지정 |
| 문제 진단 화면 열기 | 개발자 도구(장애 확인용) |
| 종료 | 메신저 완전 종료 |

### 2.3 화면 모드

| 모드 | 설명 |
|------|------|
| **기본 화면** | 왼쪽 목록 + 가운데 대화 + 오른쪽 상세/달력 |
| **미니 화면** | 좁은 창. 친구·채팅·더보기 탭으로 단순하게 사용 |

설정에서 “시작할 때 기본/미니”를 지정할 수 있습니다.

## 3. 대화(채팅)

### 3.1 1:1 대화

1. 왼쪽 목록에서 직원 이름을 클릭합니다.
2. 아래 입력칸에 글을 쓰고 **전송** 또는 **Enter** 합니다.
3. 상대가 읽고 있으면 읽음 표시가 갱신될 수 있습니다.

검색창에 **이름·부서·층**을 입력하면 목록을 좁힐 수 있습니다.

### 3.2 채널·그룹

| 종류 | 설명 |
|------|------|
| **전체 공지** | 가능한 많은 직원에게 방송 |
| **부서 채널** | 같은 부서로 등록된 직원에게 |
| **층 채널** | 같은 층으로 등록된 직원에게 |
| **그룹** | 직접 고른 멤버끼리의 대화방 (`+`로 생성) |

채널 이름 옆 배지로 **안 읽은 메시지 수**를 표시합니다.  
채널·섹션 순서는 드래그(⠿)로 바꿀 수 있습니다.

### 3.3 쪽지

채팅방을 열지 않고, 선택한 사람들에게 **한 번에 짧은 글**을 보냅니다.  
왼쪽 **✉️ 쪽지** 또는 빈 화면의 “채팅방 없이 쪽지 보내기”로 엽니다.

### 3.4 답장·리액션·긴급

| 기능 | 설명 |
|------|------|
| **답장** | 특정 메시지에 인용하며 답함 |
| **리액션** | 메시지에 이모지 반응 |
| **긴급 (🚨)** | 긴급으로 표시해 전송. 알림이 더 눈에 띔 |
| **공지 고정 (📌)** | 해당 대화방 상단에 중요 글 고정 (대화방 핀) |

### 3.5 예약 전송 (⏰)

지금 보내지 않고, 지정한 시각에 자동으로 보냅니다.  
예약 건수는 대화 화면에 표시되며 취소할 수 있습니다.

### 3.6 빠른 문구 (💬)

자주 쓰는 문장을 저장해 두고 한 번에 넣습니다.  
문구 추가·삭제는 관리 화면에서 합니다.

### 3.7 대화창 도구

| 버튼 | 기능 |
|------|------|
| 사진·파일·링크 모아보기 | 이 대화의 첨부·링크만 모아 봄 |
| 대화창 비우기 | **화면만** 비움. DB·백업·로그의 기록은 남음 |
| 대화 내용 검색 | 이 대화방 안에서 검색 |

대화방을 열면 최근 메시지(약 **200개**)가 먼저 보입니다.  
그보다 오래된 내용은 **검색** 또는 **전체 대화 기록**으로 찾습니다.  
메시지는 기간이 지나도 **자동 삭제되지 않습니다.**

## 4. 파일·사진·화면 캡처

### 4.1 사진

- 📎 파일 선택, 또는 입력칸에 **Ctrl+V** 붙여넣기
- 전송 전 **자동 압축** (긴 변·화질 조정) → 병원망에서 부담을 줄임
- 보낸 사진은 클릭하면 크게 볼 수 있습니다

### 4.2 일반 파일

| 크기 | 동작 |
|------|------|
| 약 250KB 이하 | 메시지에 실어 전송 |
| 250KB ~ **50MB** | 1:1 또는 **그룹**에서만 분할 전송 (상대가 **온라인**이어야 함) |
| 50MB 초과 | 전송 불가 → 공유 폴더 등 이용 |

**전체 공지 / 부서 / 층 채널**에는 큰 파일을 보낼 수 없습니다.  
큰 파일은 1:1 또는 그룹으로 보내 주세요.

### 4.3 화면 캡처 (📷)

- 주 화면 전체 / 다른 화면·창 선택 / **영역만** 잘라 보내기
- 캡처 이미지도 자동 압축 후 전송

### 4.4 받은 파일 폴더

툴바의 폴더 아이콘으로 **주고받은 파일이 저장된 폴더**를 엽니다.

## 5. 알림

설정 → **메시지 알림**에서 조정합니다.

| 항목 | 설명 |
|------|------|
| 새 메시지 알림 | 켜기/끄기. 보고 있는 방은 보통 제외 |
| 알림 방식 | **토스트**(기본) 또는 Windows 데스크탑 알림 |
| 토스트 표시 시간 | 몇 초 동안 띄울지 |
| 읽음 알림 | 상대가 읽었을 때 알림 (선택) |
| 미리보기 | 알림에 메시지 내용 일부를 보일지 |

같은 상대의 연속 메시지는 알림을 묶어 보여주는 방식이 적용됩니다.  
토스트를 누르면 해당 대화로 이동할 수 있습니다.

## 6. 원내 공지사항

왼쪽 상단 **원내 공지사항**을 누르면 게시판이 열립니다.

- 모든 직원이 **열람** 가능
- **글쓰기·수정·삭제**는 공지 운영자(또는 마스터) 권한이 있을 때

운영자 계정은 마스터 관리 화면에서 등록합니다.

## 7. 일정·현황판·당직

### 7.1 오른쪽 달력

- 날짜를 고르면 그날 일정이 줄로 표시됩니다
- 병동 일정은 **병동 번호 색 배지**(예: 4·5·7·8·9)로 구분됩니다
- **🔄** 새로고침 / **📋 현황판** / **일정등록**(당직·주치의 OFF)

### 7.2 병동·RM 일정 현황판

입원·퇴원·외진·외출·외박·전원·검사 등 **병원 일정을 한눈에** 보는 화면입니다.

| 일정 유형(예) | 용도 |
|---------------|------|
| 외진 | 외래 진료 동행 등 |
| 외출 / 외박 | 환자 외출·외박 |
| 입원 / 퇴원 / 전원 | 입퇴원·전원 |
| 검사 | 검사 일정 |
| 병원 업무 / 연차 | 일반·휴가 |

현황판에서 할 수 있는 일(작성 권한 있을 때):

- 빠른 등록(병동·환자·시간·식사 취소·보호자만 외진 등)
- 병동·유형·주치의 필터
- 엑셀보내기(지원 시)
- 별도 창으로 열어 두고 쓰기

**작성자 로그인**: 공지·일정 운영자 계정으로 로그인하면 등록·수정이 가능합니다.

### 7.3 당직의·주치의 OFF

**일정등록**에서 날짜별 **당직의 / 주치의 OFF**를 관리합니다.  
달력·현황판과 연동되어 표시됩니다.

### 7.4 일정 알람

등록된 일정 시각이 가까워지면 PC 알림(또는 안내)으로 알려 줄 수 있습니다.

## 8. 이동기사 요청

채널의 **이동요청** 또는 해당 메뉴로 엽니다.

입력 예:

- 병실, 환자명, 치료명  
- 이동 위치, 치료 시간, 비고  

요청을 보내면 **등록된 이동기사 휴대폰** 쪽으로 알림이 가도록 연동되어 있습니다.  
이전 요청 목록·처리 상태 확인·수정·삭제가 가능합니다.

## 9. 전체 대화 기록

- 툴바 기록 아이콘, 미니 모드 **기록**, 트레이 메뉴, **Ctrl+Alt+E**

- 필터: 전체 / 사진 / 파일 / 링크 등

## 10. 환경 설정

열기: 톱니바퀴 버튼 · 미니 모드 설정 · 트레이 **환경 설정**

### 10.1 프로필

- 사진, 성명, 층, 부서, 직급, 내선, 휴대폰  
- 근무 상태: 온라인 / 진료·치료 중 / 자리 비움  

이 정보는 다른 직원 목록·상세 정보에 보입니다.

### 10.2 목록·화면

| 항목 | 설명 |
|------|------|
| 목록 분류 | 층별(기본) 또는 부서별 |
| 목록 프로필 사진 | 켜기/끄기 |
| 기본 화면 모드 | 기본 / 미니 |
| UI·채팅 글꼴·글씨 크기 | 보기 편하게 조정 |
| 맞춤법 검사 | 입력 시 밑줄·제안 (전문 용어는 오탐 가능) |
| Windows 시작 시 자동 실행 | 켜기/끄기 |

### 10.3 파일 수신

- 자동 저장 / 물어볼지 선택  
- 다운로드(저장) 폴더 지정  

### 10.4 네트워크 상태

설정 화면에 UDP(사용자 검색)·TCP(메시지 연결) 상태가 표시됩니다.  
목록이 비면 **새로고침**을 눌러 보세요.

### 10.5 업데이트

- 업데이트 소스는 **GitHub** (`version.json` 확인)
- 설정에서 **지금 확인**으로 새 버전 받기
- Private 저장소인 경우 PC에 **읽기용 토큰 파일**이 필요할 수 있음  
  → 자세한 내용: `docs/GitHub-업데이트.md`
- 옛 PC·망 제약 시 **Z드라이브 브리지**로 공유하는 방법이 있음  
  → `docs/Z드라이브-브리지.md`
- 마스터는 온라인 PC에 **강제 업데이트**를 보낼 수 있음

### 10.6 백업

설정에서 **대화 기록 백업** 등을 실행할 수 있습니다.  
자동 백업·오래된 진단 로그 정리는 프로그램이 주기적으로 수행합니다.  
(진단용 로그 파일은 약 14일 보관. **채팅 DB는 기간으로 자동 삭제하지 않음**)

## 11. 관리자 기능 (마스터·운영자)

### 11.1 마스터 인증

자물쇠 아이콘으로 마스터 로그인합니다.  
마스터는 예를 들어 다음을 할 수 있습니다.

- 직원 프로필(표시 정보) 수정  
- 공지 운영자 계정 발급·권한(당직 관리 등)  
- 구버전 PC **강제 업데이트**  
- Z드라이브에 업데이트 공유(환경에 따라)  

### 11.2 공지·일정 운영자

마스터가 만든 계정으로 로그인하면, 여러 PC에서  
공지 작성·일정/당직 등록을 할 수 있습니다.

## 12. 네트워크·다른 층

| 항목 | 설명 |
|------|------|
| 존재 알림 | 약 수 초마다 “나는 켜져 있음” 신호를 보냄 |
| 같은 대역 | 브로드캐스트로 빠르게 발견 |
| 다른 층 대역 | 설정된 서브넷(예: 192.168.122 / 123)에 **개별 주소로** 신호 → 라우터가 브로드캐스트를 막아도 목록에 잡히기 쉬움 |
| 메시지·파일 | 상대 IP로 TCP 연결. 텍스트가 되는 상대면 사진·파일도 같은 조건 |

주의:

- 큰 파일은 상대가 **온라인**이어야 함  
- PC 방화벽이 TCP **41235** / UDP **41234** 를 막으면 장애가 날 수 있음  
- 새 층에 **새 IP 대역**이 생기면 프로그램의 대역 목록에 추가가 필요할 수 있음

## 14. 자주 묻는 점

**Q. 창을 닫으면 메신저가 꺼지나요?**  
A. 아니요. 트레이에 남습니다. 완전히 끄려면 트레이에서 **종료**를 누르세요.

**Q. 두세 달 전 대화도 볼 수 있나요?**  
A. 네. DB에서 지우지 않습니다. 화면에는 최근 위주로 보이므로 **검색·전체 기록**을 쓰세요.

**Q. 대화창 비우기를 하면 기록이 사라지나요?**  
A. 화면에만 안 보입니다. 백업·전체 기록·DB에는 남습니다.

**Q. 다른 층에 파일·사진을 보내도 되나요?**  
A. 1:1(또는 그룹)이고 상대가 목록에 온라인으로 보이면 됩니다.

**Q. 업데이트가 “이미 최신”인데 새 기능이 없어요.**  
A. 업데이트 주소가 GitHub인지 설정에서 확인하세요. 자세한 절차는 `docs/GitHub-업데이트.md`를 보세요.

**Q. 목록에 사람이 안 보여요.**
